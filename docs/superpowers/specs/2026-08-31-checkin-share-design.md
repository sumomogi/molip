# 체크인과 공유 카드

하루의 시작과 끝을 사용자가 직접 찍고, 마감할 때 "근무 몇 시간 중 몰입 몇 시간"을
정사각 PNG로 만들어 클립보드에 올린다.

## 목적

지금 앱은 세션만 안다. 오늘 얼마나 집중했는지는 세션 합계로 알 수 있지만,
그게 하루 중 얼마나 되는지는 모른다. 세 시간 집중한 날이 여섯 시간 근무한 날인지
열두 시간 근무한 날인지에 따라 뜻이 전혀 다르다.

체크인이 그 분모를 만든다.

```
체크인 ─────────────────────────────── 체크아웃
   ├──세션──┤   ├─세션─┤    ├──세션──┤
   근무시간 = 체크아웃 − 체크인
   몰입시간 = 그 사이에 시작한 세션들의 합
   비율    = 몰입 / 근무
```

## 용어

`출근`이 아니라 `체크인`을 쓴다. 사무실에 가는 것만이 근무가 아니고,
집에서 일하는 사람에게 출근은 맞지 않는 말이다.

## 저장

**새 파일을 만들지 않는다.** 열려 있는 체크인 시각 하나만 `UserDefaults`에 둔다.

```
Prefs.checkedInAt: Date?
```

몰입 시간은 이미 있는 `sessions.jsonl`에서 그 구간에 시작한 세션을 걸러 더한다.
지난 날들의 근무 기록은 쌓지 않는다 — 요청받은 것은 체크인과 공유이지 근무 이력이
아니다. 필요해지면 그때 파일을 붙인다.

### 체크아웃을 잊었을 때

앱이 시작될 때 체크인이 **어제 이전 날짜**면 조용히 버린다.

"근무 31시간"이라 적힌 카드를 공개적으로 올리는 것보다 그날 숫자를 잃는 편이 낫다.
자정을 넘겨 일하고 그 사이 앱까지 재시작한 경우에만 손해를 본다.

## 계산

전부 순수 함수다. 입력은 체크인 시각, 체크아웃 시각, 세션 배열.

```swift
struct Workday {
    let checkedIn: Date
    let checkedOut: Date
    let workSeconds: Int      // 체크아웃 − 체크인
    let focusSeconds: Int     // 구간 안에서 시작한 세션의 합
    var ratio: Double         // focus / work, 0...1
}
```

세션은 **시작 시각**이 구간 안에 있으면 통째로 센다. 구간 끝에 걸친 세션을 잘라
세는 것은 정확하지만, 체크아웃을 누르는 순간에 세션이 돌고 있는 경우는
체크아웃이 먼저 세션을 닫으므로 실제로는 생기지 않는다.

비율은 1.0을 넘지 않게 자른다. 시계가 튀거나 체크인을 늦게 찍으면 몰입이 근무보다
길어질 수 있는데, 101%는 사람을 혼란스럽게 할 뿐이다.

## 화면

### 타이머 화면의 근무 줄

아래 버튼은 이미 셋(`시작` `기록` `설정`)이다. 넷째를 넣으면 영어에서 240pt를
넘긴다. 그래서 근무 상태는 자기 줄을 갖는다 — 설정 화면 행들과 같은 골격으로
왼쪽에 라벨, 오른쪽에 컨트롤.

```
세트 1 / 2                     세트 1 / 2

              체크인            근무 3:24      체크아웃
──────────────────             ──────────────────
시작      기록  설정            시작      기록  설정

   체크인 전                        체크인 후
```

근무 시간은 분 단위로만 갱신한다. 초 단위로 움직이면 곁눈에 걸린다 —
메뉴바 게이지를 숫자 없이 만든 것과 같은 이유다.

### 마감 화면

체크아웃을 누르면 넘어간다. 복사하기 전에 숫자를 눈으로 보고, 공유하지 않고
그냥 닫을 수도 있어야 한다.

```
마감

8:12
근무

▓▓▓▓▓▓▓▓▓░░░░░░░░
몰입 4:10 · 51%

09:12 – 17:24
──────────────────
닫기        이미지 복사
```

`이미지 복사`를 누르면 그 자리에서 라벨이 `복사됨`으로 바뀐다. 알림을 띄우지
않는다 — 사용자가 방금 누른 버튼이고, 재촉하지 않는 톤을 지킨다.

## 카드

1080×1080 PNG. 정사각이라 어느 SNS에서도 잘리지 않는다.

무채색만 쓴다. 앱과 같은 언어 — 색 없이 명도만. 타임라인에서 작게 보여도 읽히도록
몰입 시간을 크게 둔다.

```
┌──────────────────────────┐
│                          │
│  2026-08-31 월           │
│                          │
│  4:10                    │
│  몰입                    │
│                          │
│  ████████░░░░░░░░░░      │
│  근무 8:12 중 51%        │
│                          │
│                    몰입  │
└──────────────────────────┘
```

`NSImage` + `NSGraphicsContext`로 직접 그린다. 에셋 카탈로그를 쓰지 않는 기존
방침 그대로다 — 이 맥에는 `actool`이 없다.

## 공유

`NSPasteboard`에 PNG를 올린다. 그게 전부다.

macOS 공유 시트를 쓰지 않는다. 요즘 공유 시트에는 X·Threads 같은 SNS가 거의
없어서 메모와 메시지만 나온다. 클립보드는 어디에든 붙일 수 있고, 올리기 전에
사용자가 내용을 한 번 더 보게 된다.

네트워크 코드도 API 키도 넣지 않는다. 그것을 시작하면 이 앱의 성격이 바뀐다.

## 언어

새 문자열은 전부 `Strings.swift` 표에 넣는다. 세 언어 모두 채운다.

`checkIn`, `checkOut`, `onDuty`(근무), `closing`(마감), `copyImage`, `copied`.

기존 `.work` 키는 설정 화면의 "집중" 길이라서 재사용하지 않는다.
같은 대상을 두 이름으로 부르지 않는다는 규칙의 반대 경우 — 다른 대상이므로
다른 키를 쓴다.

카드에 들어가는 문자열도 같은 표에서 가져온다.

## 검증

| 확인할 것 | 방법 |
|---|---|
| 구간 밖 세션 제외 | 체크인 전·체크아웃 후에 시작한 세션 |
| 경계 | 체크인과 정확히 같은 시각에 시작한 세션 |
| 세션 0 | 체크인만 하고 하나도 안 돌린 하루 |
| 비율 상한 | 몰입이 근무보다 긴 입력 → 1.0에서 멈춤 |
| 근무 0초 | 체크인 직후 체크아웃 → 0으로 나누지 않음 |
| 전날 체크인 폐기 | 어제 날짜 체크인이 앱 시작 시 사라지는지 |
| 카드 | 실제로 PNG를 렌더해 1080×1080이고 비어있지 않은지 |

## 범위 밖

- SNS 직접 연동
- 카드 문구 커스터마이즈
